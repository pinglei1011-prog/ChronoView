ChronoView 0.1.0 — 第一阶段 MVP

使用方法：
1. 双击 ChronoView.exe。
2. 点击“选择文件夹”，选择照片库最外层目录。
3. 展开“按年份”或“按月份”浏览；双击照片查看大图。
4. 新增照片后按 F5 刷新；大图可用左右方向键切换、滚轮缩放、F11 全屏。

请保留整个文件夹（包含 _internal），不要只复制 EXE。
本绿色版包含 Python 和 Qt 运行依赖，不需要另装 Python。
程序完全本地运行，只读取原始照片和视频，不移动、重命名、修改或删除它们。
设置、缓存和日志保存在本机当前用户目录，不保存在照片库内。

当前照片支持 JPG/JPEG、PNG、WebP、BMP。
HEIC/HEIF 需要可选解码器，本构建未包含。
视频仅参与网格展示、计数、时间排序和年月分类，本版本尚不能播放。
本版已在开发电脑 Windows 11 x64 验证；其他电脑及 Windows 10 干净环境仍需验证。
完整验证详情见 VALIDATION.md。视频播放、SQLite 增量索引和正式安装版在后续阶段实现。
