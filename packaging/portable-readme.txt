ChronoView V1.0 — 本地照片与视频浏览

双击 ChronoView.exe 直接进入主界面的隐私页；独立启动欢迎页已移除。点击打开照片库/全部照片或选择文件夹后才显示媒体。
请保留整个目录，包括 _internal；不需要另装 Python 或系统视频解码器。

全部照片直接显示所有照片和视频；左侧选择年份可浏览月份卡片，点击月份查看对应媒体。返回按钮逐级返回全部照片。
左侧也按全部照片/年份/月份分层；有未识别日期文件时才在全部照片的年份之后显示该分类。
双击照片查看大图，可用画布左右中间的箭头或方向键切换。视频缩略图中央显示播放标记；单击视频进入播放。
单击视频画面或按空格暂停/继续，双击视频画面切换全屏。
视频可拖动进度、调节音量；照片支持缩放和平移。F11 全屏，Esc 返回。
首次扫描后保存本地索引，再次启动优先恢复。新增、删除或修改文件后按 F5 刷新。
硬盘断开仍保留离线列表，重连后刷新；盘符改变后重新选择目录。

完全本地运行，原始文件只读访问，不修改、移动、重命名或删除照片和视频。
已在本机验证 H.264 MP4、H.265 MOV、H.264 MKV；其他编码及干净 Windows 10/11 电脑未全面验证。
HEIC/HEIF 为可选能力，本构建未包含。缓存暂不自动清理。

本软件使用 Qt / PySide6 LGPLv3 和 FFmpeg LGPLv2.1+ 动态库。
许可、归属及替换说明见 licenses 文件夹；配套第三方源码包请随绿色版保留和分发。
详细验证及未验证项见 VALIDATION.md。此次没有制作正式安装包。
