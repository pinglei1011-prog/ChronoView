# ChronoView 0.2.20 主界面隐私页验证

日期：2026/11/24（北京时间）。

## 改动

在现有浏览界面左侧与右上角提供隐私页入口（Ctrl+L），切换后主界面保留，中部显示中性提示和继续浏览按钮。媒体模型清空显示，年月/数量/路径/状态隐藏，后台缩略图暂停，内存中的照片库保留以便继续。取消选目录/F5/主题切换不会揭开媒体；扫描成功、取消或失败保持隐私页。继续浏览恢复原分类，主动点击全部照片可显示完整列表。

查看器内 Ctrl+L 关闭查看器并释放播放器，再显示主界面隐私页；查看器退出时不自动恢复背景封面。启动欢迎页与记忆目录选项仍保留。原始媒体只读，不提供密码或加密，不清除已有索引/缓存。
