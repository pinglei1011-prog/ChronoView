# ChronoView 0.2.0 第二阶段验证记录

日期：2026/11/24（北京时间）。在现有项目和 v0.1.0 基础上开发，未改动该标签与原绿色版。

## 环境与结果

Windows 11 x64（10.0.22631）、Python 3.12.16、PySide6 / Qt 6.10.3、Pillow 12.3.0、pytest 9.2.0、PyInstaller 6.22.3。Qt 自带 FFmpeg 7.1.3；未安装系统 FFmpeg 或额外 HEVC 扩展。

- **完整自动化回归：49 passed，约 10.70 秒。** 保留第一阶段所有测试函数，原视频占位提示断言随新播放行为更新；增加 13 项视频、导航和索引检查。
- 使用开发专用 FFmpeg 生成 320×180、12fps、约 3 秒、AAC 音轨的 H.264 MP4、H.265 MOV、H.264 MKV，测试文件都在临时目录。应用分发包不包含该编码工具。
- 三种视频真实封面、比例、时长、磁盘缓存复用、原文件哈希不变均通过。
- 三种视频真实解码帧、播放/暂停、跳到中间、音量值、播放器销毁均通过。照片与视频左右键连续切换、全屏进出通过。
- 损坏视频、缺失文件显示错误提示；队列中同时解码不超过 2 个视频，UI 定时器持续触发，退出取消队列通过。
- 2026 年点击后显示全年、展开月份，月份按 1、2 月排列；顶部月份按钮筛选及返回全年、照片视频混合排序通过。
- SQLite 快照保存、变更对账、库隔离、空库恢复、断开后的离线列表和启动不调用递归扫描通过。原取消/不可访问保护和刷新发现新增文件测试继续通过。

## 打包版验证

绿色版：`dist/ChronoView-0.2.0/ChronoView.exe`，未制作安装版。

`scripts/verify_portable.py` 从含中文/空格的其他工作目录启动 EXE；清除 PYTHONHOME、PYTHONPATH，将 PATH 缩减到 Windows System32，使用独立设置和临时多层中文照片库。

实际结果：**通过，退出码 0，诊断流程约 2.58 秒。** 已核对 JPG/PNG 和三种视频封面缓存文件，且打包版完成以下原生窗口流程：

1. 递归扫描照片与视频混合库。
2. 提取真实视频封面和时长。
3. 年份、月份筛选。
4. 照片解码和缩放。
5. 三种视频逐个播放、暂停、拖动进度、调整音量、进入与退出全屏。

机器可读结果：`work/packaged-v2-media.json`。程序内部诊断通过实际视频输出帧和播放器状态检查，并非仅检查进程能否启动。

另使用 computer-use 检查了真实 Windows 窗口：视频网格有真实封面及 0:03 时长；单击 H.265 MOV 后，屏幕上实际显示变化的测试视频画面和播放控件。硬件视频表面不能由普通 QWidget.grab 完整捕获，故内部测试截图的空白视频区域不等于播放失败；原生窗口捕获已确认画面正常。

## 性能测量

在开发电脑本地盘，用 20,000 个合成空 JPG 做元数据测试：

| 操作 | 时间 |
|---|---:|
| 完整目录枚举和文件名日期解析 | 2.707 秒 |
| SQLite 索引对账写入 | 0.292 秒 |
| SQLite 快照加载 | 0.082 秒 |

脚本：`scripts/benchmark_index.py`，原始记录 `work/performance.json`。它只测元数据，不代表真实照片解码、SATA SSD 吞吐或滚动帧率。

## 修复与打包处理

- 修复快速 seek/resume 后同步 stop 可能卡住：改为 Qt 原生队列 stop + deleteLater，验证实际销毁完成；旧播放器信号断开，错误信号加代次检查。
- 视频封面禁用音频输出，图片任务最多 3 个线程、视频封面最多 2 个异步播放器，总请求上限 48，内存缩略图上限 192。
- 图片继续使用原 v1 缓存键，视频使用独立 video-v2 键并保存时长；读取失败可在刷新后重试。
- SQLite 只在完整且无错误的扫描后提交；取消、断开和部分权限错误不覆盖持久化快照。
- 保留第一阶段的 ICU 过滤修复；打包包含 Qt Multimedia、FFmpeg DLL 和多媒体插件。移除了不使用的 PDF、虚拟键盘和 QML/Quick 动态库，避免附带无关模块。
- 动态库实际许可/编译配置已导出检查；绿色版带许可证、归属与替换说明，另提供版本匹配的第三方源码压缩包。没有静态链接或捆绑开发专用 GPL 编码工具。

## 未验证与已知边界

- 未在其他干净 Windows 10/11 电脑或虚拟机上验证；未专项验证 4K、多显示器和不同 DPI。
- 未使用真实 SATA 移动硬盘做物理拔插、休眠、I/O 超时或盘符变更实测。不可访问和离线恢复由临时路径模拟，盘符改变需重新选择目录。
- 未专项验证 AVI、HEIC/HEIF、HDR、Dolby Vision、10-bit、超高码率/长视频及所有手机编码组合。不支持的编码或损坏文件会尝试报错，不作全格式保证。
- AAC 音轨参与解码与音量控件测试，但没有做扬声器/耳机主观听感、音画同步或设备切换检查。
- 再次启动恢复索引，不自动发现库内变化；用户需手动刷新。刷新仍完整枚举文件，数据库只更新变化记录，尚无目录监听或文件系统日志级增量发现。
- 磁盘缓存暂不自动清理；大量未变更素材可复用缓存，失效缓存可能继续占空间。
- 未做数万张真实照片及视频的长时间滚动、内存和拔插压力测试；小素材队列/UI 定时器测试不能代替该验证。
- 已附许可证与源码分发材料，但未做商业发行的完整法律或编解码专利审查。
- 按本次要求，没有生成或验证正式安装包。
