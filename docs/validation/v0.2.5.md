# ChronoView 0.2.5 网格与返回按钮验证

日期：2026/11/24（北京时间）。保留历史绿色版和 v0.1.0 标签，原始媒体保持只读。

## 改动

- 按 Qt 的实际 IconMode 排版边界计算宽度，计入隐藏滚动条的预留区与末端边界像素，避免最后一列提前换行。
- 照片和文字相册网格在视口、窗口或卡片尺寸改变后合并重排；不重新扫描、不改变媒体顺序。
- 返回按钮使用随包 SVG 图标，明确显示“返回 2026年”或“返回全部照片”，提供深浅主题悬停、按下和键盘焦点样式。
- 全部照片首页隐藏无效返回入口，月份与年份仍逐级返回。

## 实际通过

- **62 项回归通过，12.16 秒。** 保留第一阶段与第二阶段原有测试，新增实际网格位置回归：24/72 张生成照片、侧栏收放、1100/1280/1282 像素窗口、110/144/180 缩略图尺寸，首行右侧余量不超过 32 像素，无水平滚动，路由和媒体顺序不变。
- **原生 Windows 平台额外 3 项 UI 用例通过，2.05 秒。** 验证上述几何场景和年份/月导航及返回图标；覆盖内容不足以滚动和需要滚动的情况。
- scripts/visual_check.py 通过：1280 像素窗口隐藏侧栏，144 缩略图时第一行 8 项，视口右侧余量 20 像素；Ctrl+B、展开按钮和状态保存正常。已目视检查浅色、深色排版及返回按钮。
- 截图：work/qa-sidebar-hidden-light.png、work/qa-sidebar-hidden.png、work/qa-years.png、work/qa-months.png。
- 打包版媒体与旧索引回归：通过。EXE 在独立中文/空格工作目录、移除 Python 与外部 Qt 插件路径后，照片解码、年月导航、H.264 MP4/H.265 MOV/H.264 MKV 封面及播放/暂停/拖动/音量/全屏均通过。修改生成素材后恢复旧 SQLite 索引，仍可读取并生成当前指纹的缓存。记录：work/packaged-0.2.5-media.json、work/packaged-0.2.5-stale-index.json。

## 交付与边界

新版为 dist/ChronoView-0.2.5/ChronoView.exe。第三方依赖及配套源码版本未改变，没有制作安装包。

照片不足一行或最后一行数量较少时，尾部会自然留空；完整行使用可用宽度，保留滚动条预留区及少量取整余量。

历史验证与既有边界见 docs/validation/v0.2.4.md 及更早记录。本次未新增干净电脑、多 DPI 显示器、真实硬盘拔插、HDR 等兼容性验证。
