# ChronoView 0.2.21 移除独立启动欢迎页验证

日期：2026/11/24（北京时间）。

## 改动

删除独立启动欢迎页类与外层页面切换容器，主窗口 centralWidget 直接为浏览主界面。正常启动默认选择主界面隐私页，侧栏、主题和隐私入口可用，照片、目录、年月及数量仍隐藏。没有自动扫描/恢复索引；中间按钮或全部照片可主动打开记忆目录，无记录则选目录。取消选择保持隐私页，可再次点击。侧栏保留目录记忆选项。

浏览中的隐私页、继续浏览、Ctrl+L、查看器关闭/停止视频、后台扫描结果保护保留。原始媒体只读，不提供密码或加密，不清除既有索引/缓存。
