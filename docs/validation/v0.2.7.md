# ChronoView 0.2.7 未识别日期按需显示验证

日期：2026/11/24（北京时间）。保留历史绿色版和 v0.1.0 标签，原始媒体保持只读。

## 改动

- 没有未识别日期文件时，侧栏不显示该入口；有内容时才在全部照片下、年份之后显示。主区域已有同样条件，继续保持。
- 刷新后根据实际数量显示或隐藏；正在查看未识别日期且刷新后已无内容时，自动回到全部照片，避免停留在没有导航入口的空页。
- 后台扫描期间不因临时批次缺少未识别文件而提前跳转，取消或离线失败仍恢复原有列表。

## 验证

- 63 项完整回归通过，12.97 秒。
- 原生 Windows 额外 2 项未识别日期导航及刷新检查通过，1.36 秒。
- 新增生成素材场景：初始无未识别文件，新增后刷新出现入口与卡片，保留所选月份；进入未识别日期后由测试代码更正生成文件的名称，再刷新入口和卡片消失，回到全部照片。测试不会修改用户原始文件。
- 打包版媒体和旧索引检查：通过。独立中文/空格工作目录、去除外部 Python/Qt 路径后，照片解码、年月导航、H.264 MP4/H.265 MOV/H.264 MKV 封面和播放控制均通过；文件变化后从旧索引恢复仍可读取。记录：work/packaged-0.2.7-media.json、work/packaged-0.2.7-stale-index.json。
