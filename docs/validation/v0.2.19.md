# ChronoView 0.2.19 欢迎页主按钮验证

日期：2026/11/24（北京时间）。

## 原因与修复

无保存目录时，旧版将打开上次照片库按钮禁用，但 primary 样式仍显示蓝色。新版无记录时改为启用的打开照片库，调用目录选择；提示尚无保存位置，并隐藏重复的次按钮。有记录时保持原来的继续和选择其他文件夹。取消选择不退出隐私页；关闭记忆仍能通过主按钮正常选目录。

## 验证

76 项完整回归通过，1 项原生专项跳过，13.21 秒。原生 Windows 隐私相关 7 项通过，3.34 秒；通过真实鼠标事件验证主按钮调用目录选择、取消后保持隐私、确认后进入浏览、记忆开/关下保存行为、有记录继续与重启保护。目录选择返回值使用临时生成的测试照片库，不修改原始媒体。已检查无记录欢迎页深浅截图 work/qa-first-open-light.png、work/qa-first-open-dark.png。打包 EXE 在精简 PATH、中文/空格目录下检查通过：主动打开前的隐私欢迎页、完整媒体列表、年月导航、照片解码缩放、H.264 MP4/H.265 MOV/H.264 MKV 封面/播放控制、旧索引恢复读取均成功。报告 work/packaged-0.2.19-media.json、work/packaged-0.2.19-stale-index.json。无目录主按钮的目录选择交互使用同版源码在原生 Windows 下验证，测试替代选择器返回值。
