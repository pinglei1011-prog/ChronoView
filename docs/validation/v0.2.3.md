# ChronoView 0.2.3 文字卡片验证

日期：2026/11/24（北京时间）。旧版标签与绿色版保留，未改动原始媒体。

## 改动

- 全部照片页面中的年份卡片不再显示封面。
- 年份页面中的月份卡片不再显示封面。
- 卡片使用纯色背景、名称和数量，保留月份数、点击/Enter 进入与逐级返回。
- 相册模型不再挑选代表媒体，卡片视图不依赖缩略图服务，因此这些层级不请求照片或视频解码。
- 进入具体月份后，原有照片缩略图、视频封面和播放逻辑继续使用。

## 验证

- **60 项自动化测试通过，约 11.10 秒。** 更新了旧封面选择断言；既有层级导航测试检查年份/月份页面的缩略图任务和内存缓存均为空，再进入月份核对媒体列表。
- 用已有合成素材渲染年份、月份和深色页面，已目视检查文字卡片及统计，无任何照片封面。具体月份的媒体网格继续正常显示缩略图。
- 源码及打包版依赖保持原版本，第三方许可证与源码配套包沿用。
- 打包版媒体与旧索引回归：通过。独立中文/空格目录、移除 Python 与外部 Qt 插件路径后，年月层级、图片解码、H.264 MP4/H.265 MOV/H.264 MKV 播放控制及源文件变更后的旧索引恢复均通过。结果见 work/packaged-0.2.3-media.json 与 work/packaged-0.2.3-stale-index.json。

截图位于 work/qa-years.png、work/qa-months.png、work/qa-dark.png、work/qa-media.png。
