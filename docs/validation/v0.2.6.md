# ChronoView 0.2.6 年份顺序与日期分类验证

日期：2026/11/24（北京时间）。保留历史绿色版和 v0.1.0 标签，原始媒体保持只读。

## 改动

- 左侧年份导航与全部照片的年份卡片统一按年份升序排列。
- 左侧未识别日期移到全部照片下，与年份同级，放在所有年份之后。
- 主区域仍在有未识别文件时显示对应卡片；左侧保留数量为 0 时的入口。进入、选中、返回和刷新沿用现有路由。
- 月份按 1 月到 12 月排列，月份内照片和视频仍按所选文件名时间顺序混合排列。
