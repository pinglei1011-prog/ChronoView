# ChronoView 0.2.10 查看器交互验证

日期：2026/11/24（北京时间）。在现有项目继续修改，保留原始媒体与历史绿色版。

## 改动

- 照片画布左右两侧垂直居中新增半透明圆角 SVG 箭头，窗口缩放/全屏时重新定位；首尾禁用，不循环越界。顶部按钮与左右键保留，照片/视频按原有顺序连续浏览。
- 视频缩略图播放标记移到封面中央，使用半透明圆形底和白色三角；时长仍在右下角。加载或失败时保留清晰提示，避免居中图标覆盖文字。
- 左键单击视频画面立即暂停或继续；双击撤销第一击带来的切换并全屏，避免最后一次释放再次切换。切换文件时清空单/双击跟踪；全屏切换若丢失最后一次释放，下一次正常按下仍可开始新点击。
- 扩展混合导航测试时复现旧音频释放死锁。原生栈显示 GUI 在 QMediaPlayer 析构时等待工作线程，音频工作线程在 QObject 析构/disconnectNotify 中等待 Python GIL。GUI 线程先解除旧 QAudioOutput 的 deviceChanged/volumeChanged/mutedChanged 连接，随后继续异步停止和释放；新播放器重新连接通知。未引入延迟睡眠、额外释放线程或新媒体依赖。
