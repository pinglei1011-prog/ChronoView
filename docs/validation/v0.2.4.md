# ChronoView 0.2.4 侧边栏切换验证

日期：2026/11/24（北京时间）。保留之前的标签和绿色版，未修改用户原始媒体。

## 改动

- 收起按钮位于侧边栏品牌标题右侧；收起后，主区域左上角提供展开按钮。
- Ctrl+B 切换显示/隐藏；QSettings 保存 sidebar_visible，默认保持原有显示侧栏行为。
- 隐藏侧栏后网格自动扩展，继续保留当前页面、排序和媒体条目，不重新扫描照片库。
- 隐藏时若焦点在侧栏中，则焦点移到当前浏览页；按钮提供中文名称、悬停提示及键盘焦点样式。
- 年份、月份纯文字卡片和具体月份的照片/视频缩略图逻辑不变。

## 验证

- **60 项原有回归通过，约 10.66 秒。**
- scripts/visual_check.py 的原生界面场景通过：点击收起后侧栏隐藏，展开按钮仍可见，媒体视口宽度增加，当前月份和媒体顺序不变，设置保存为隐藏；Ctrl+B 恢复，再次收起后可用展开按钮恢复，保存设置为显示。
- 已目视检查侧边栏右上角按钮位置、侧栏隐藏后主区域左上角展开入口、深色宽幅媒体网格，以及原有浅色年份页面。
- 截图：work/qa-light.png、work/qa-sidebar-visible.png、work/qa-sidebar-hidden.png。
- 打包版独立媒体及旧索引检查：通过。独立中文/空格工作目录、移除 Python 与外部 Qt 插件路径后，年月层级、照片解码、H.264 MP4/H.265 MOV/H.264 MKV 播放控制及过期索引恢复均通过。记录见 work/packaged-0.2.4-media.json 和 work/packaged-0.2.4-stale-index.json。
