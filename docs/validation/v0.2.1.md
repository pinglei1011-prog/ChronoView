# ChronoView 0.2.1 年月相册浏览验证

日期：2026/11/24（北京时间）。在现有第二阶段代码上调整导航，不重建项目。第一阶段标签 v0.1.0、0.1.0 和 0.2.0 压缩包保留。

## 当前浏览逻辑

全部照片（年份相册） → 某年（月份相册） → 某月（照片、视频缩略图）。

- 主区域使用带代表封面和数量的相册卡片，单击或 Enter 进入下一层。
- 侧栏同样只有全部照片 → 年份 → 月份，另保留未识别日期；移除重复按年份/按月份节点。
- 年份从新到旧，月份从 1 月到 12 月，只显示实际有内容的月份。
- 月份内沿用文件名时间混合排序，支持新到旧和旧到新。
- 返回按钮按月份 → 年份 → 全部照片逐级返回。刷新后保留当前月份和祖先展开状态。
- 文件名日期无法识别的文件可以从侧栏或首页“未识别日期”卡片查看。
