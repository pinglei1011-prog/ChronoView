## 已确认的问题与修复

用户指定 F:/photo/VID20240310142942.mp4，Windows 自带播放器正常。该文件为 H.264、3840×2160、约 59.07fps、约 51Mbps 总码率、1.659 秒。只读取媒体信息和播放，没有转码、改写文件或写入照片库。

- Qt 日志显示使用 d3d11va，HW device is OK；并非本次测量中硬件解码未启用。
- 完整相册背景会继续用 QMediaPlayer 提取封面，VideoThumbnailJob.on_frame 在 GUI 线程调用 QVideoFrame.toImage()，需要 GPU 帧回读和转换。其与前景播放并行时，复现到明显 UI 阻塞。
- 修复为查看器优先：打开前暂停新缩略图请求，取消并暂存正在进行的视频封面任务，完成解码器延迟释放后打开查看器；关闭后恢复队列和可见项请求。已在运行的图片工作线程仍可完成。
- 保留 Qt 默认硬件解码选择与软件回退，不强制显卡、不更换依赖、不修改或生成原视频的代理文件。
