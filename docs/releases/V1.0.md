# ChronoView V1.0 — 2026/11/25 更新

Windows 本地照片与视频浏览器。启动直接进入主界面的隐私页，主动打开照片库后浏览全部媒体，也可按年份、月份查找；默认按文件名时间从旧到新混合排列照片和视频。原始文件只读。

## 功能

- 采用当前新版界面，统一深浅主题、侧栏、数量徽标、图标、照片网格和查看器。
- 缩略图支持“完整 / 铺满”切换与偏好保存，打开大图仍查看完整原图。

- 后台递归扫描、中文路径、SQLite 本地索引、缩略图缓存及移动硬盘离线列表。
- 照片完整缩略图、日期时间居中、大图缩放/平移/全屏、侧边箭头和方向键连续切换。
- 真实视频封面和时长、播放/暂停、进度拖动、音量、全屏、点击画面切换播放状态。
- 年份/月份导航、从旧到新或从新到旧排序、深浅主题、可隐藏侧栏。
- 主界面隐私页、Ctrl+L 隐藏媒体；查看器中使用会关闭查看器并停止视频。目录记忆可关闭。

## 下载与启动

下载 `ChronoView-1.0.0-portable-win64.zip`，完整解压后运行目录里的 `ChronoView.exe`。请保留 `_internal` 和 `licenses`；不需要另装 Python。界面和发布标签显示 V1.0，内部包版本为 1.0.0。

配套文件：`ChronoView-1.0.0-third-party-sources.zip` 提供对应版本 Qt/PySide6、FFmpeg 源码及构建信息；`ChronoView-1.0.0-SHA256SUMS.txt` 提供两个 ZIP 的 SHA-256 校验。分发绿色版时请同时保留源码包及许可证。

## 验证与边界

- 完整回归 **83 项通过、1 项专项跳过**；原生 Windows UI、隐私与视频 **46 项通过**。
- 打包版在中文/空格目录、精简 PATH 下，照片浏览、H.264 MP4/H.265 MOV/H.264 MKV 封面与播放控制、年月导航、索引恢复及隐私切换均通过。
- 绿色版与第三方源码 ZIP 在发布打包时进行完整性与 SHA-256 校验。详细记录见仓库 `VALIDATION.md`。

HEIC/HEIF 解码器未包含；其他干净 Windows 10/11 电脑、所有视频编码/驱动组合、HDR/10-bit、多显示器和长期播放尚未全面验证。缓存暂不自动清理，目录变更后按 F5 刷新。隐私页不提供密码或加密。此次发布 Windows x64 绿色版，没有正式安装包。
