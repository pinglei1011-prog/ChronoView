# ChronoView V1.1.0

视频播放改用 libmpv 0.42.0 原生窗口和 D3D11 硬件解码，保留已有照片浏览、年月导航、默认升序、缓存、索引及主界面隐私页。

- 双击视频准备好后自动播放，防止打开手势误触发暂停；单击画面暂停/继续，双击全屏。
- 播放线程不直接回调 Python，关闭异步释放，并隔离旧视频事件和控制回调。
- 提供 Windows x64 安装版和绿色版、第三方源码及静态重链接材料、SHA-256 校验。
- 安装按当前用户进行，卸载保留用户媒体、设置、索引和缓存；绿色版保留整个解压目录即可运行。

详细测试及边界见 VALIDATION.md。播放器配置优先降低负载，未承诺所有硬件/编码都无掉帧。应用未进行代码签名，安装时可能显示未知发布者。

## 本机实测

Windows 原生回归 102 项全部通过；无界面回归 92 项通过、10 项原生测试跳过（已在 Windows 模式通过）。正式 EXE 的 H.264 MP4/H.265 MOV/H.264 MKV、中文/空格目录及精简 PATH 验证通过。6 段真实视频各两轮共 12 次全片播放全部正常结束，原文件大小/修改时间不变；三个 4K 样本渲染丢帧均为 0，长竖屏样本两轮均为 9 帧，通过既定 5% 阈值。安装、覆盖安装、安装后播放和卸载保留用户文件的检查通过。

未全面测试其他电脑、驱动、HDR/10-bit/Dolby Vision、长期连续播放；HEIC 解码器不包含，缓存暂不自动清理。
