首个可运行的 **Windows 本地照片与视频浏览器 MVP**，作为后续开发可回退的基础版本。

### 已实现

- 选择内部或移动硬盘照片库，后台递归扫描任意子目录，支持中文和 Unicode 路径。
- 严格校验 IMG/VID 文件名日期，混合排序照片与视频，支持新到旧及旧到新。
- 全部照片、年份、月份、未识别日期分类与照片/视频计数。
- 照片缩略图缓存、大图查看、EXIF 方向、缩放、平移、全屏和左右键切换。
- 深浅主题、缩略图大小调节、路径记忆、手动刷新、扫描取消及不可访问保护。
- 原始媒体只读访问，不移动、重命名、编辑或删除文件。

### 下载与启动

下载 `ChronoView-0.1.0-portable-win64.zip`，完整解压后双击 `ChronoView.exe`。请保留 `_internal` 文件夹；不需要预装 Python。

`SHA256SUMS.txt` 提供绿色版压缩包的 SHA-256 校验值。

### 验证

- 36 项自动化测试全部通过。
- 本机 Windows 11 x64 源码启动与绿色版构建通过。
- 绿色版从中文/空格工作目录、移除 PATH 中的 Python 路径后正常启动，递归扫描和 JPG/PNG 缩略图生成通过。
- 原生启动界面和文件夹选择窗口已确认；打包版大图/全屏的完整手动流程、其他干净 Windows 10/11 电脑尚未验证。

### 后续范围

本版视频参与网格、计数、排序和年月分类，**尚不能播放视频，也没有视频封面**。HEIC/HEIF 为可选解码能力，本绿色版未包含。SQLite 持久化索引、真正增量扫描、离线库保存和正式安装包在后续阶段实现。

详细测试结果与边界见仓库 `VALIDATION.md`。
